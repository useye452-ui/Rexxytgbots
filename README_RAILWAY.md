# RexxyTGBot - Railway

## Required Railway Variables
- OWNER_ID=your Telegram numeric user ID
- TELEGRAM_BOT_TOKENS=token1,token2,token3

## Start command
python rexxy.py

## Deploy
1. Push these files to GitHub.
2. Railway -> New Project -> Deploy from GitHub Repo.
3. Select the repository.
4. Add OWNER_ID and TELEGRAM_BOT_TOKENS under Variables.
5. Deploy.
6. Open Deploy Logs and wait for the bot online messages.

Never commit real Telegram bot tokens to GitHub.
